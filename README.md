# [**Wattpad Content Downloader**](https://github.com/SBPhungNguyen1/wattpad-content-downloader/tree/main)

> A tiny JavaScript script to download the content of the current Wattpad chapter as a `.txt` file.

## 🎯 Why?

**I GOT TIRED OF WATTPAD NOT ALLOWING ME TO EASILY COPY THE CONTENT I'M READING.**

So I made this.

**No installation. No extension. No backend. No bullshit.**

Just run a small script directly in Wattpad's browser console and get your chapter as a `.txt` file.

## ✨ Features

- 🪶 **Lightweight** — just one JavaScript file.
- 🚫 **No installation** — no Node.js, npm, extension, or additional software.
- 📜 **Auto-scroll** — automatically scrolls to load the full chapter.
- 📄 **Plain `.txt` output** — simple and easy to read, search, or process.
- 🔒 **Runs locally** — the content stays in your browser and is not uploaded to any server.

## 🚀 How to use

1. Open the Wattpad chapter you want to download.
2. Open **Developer Tools → Console**.

   - `F12`
   - or `Ctrl + Shift + I`

3. Copy the script from this repository.
4. Paste it into the Console and press **Enter**.
5. Wait for the script to finish scrolling.
6. The `.txt` file will be downloaded automatically.

That's it.

```text
Wattpad
   ↓
Open Console
   ↓
Paste
   ↓
Enter
   ↓
📥 chapter.txt
```

## ⚠️ Note

This script extracts the **current chapter only** and relies on Wattpad's current HTML structure. If Wattpad changes its page structure, the script may need to be updated.

Please respect Wattpad's Terms of Service, copyright, and authors' rights. Use the tool responsibly and do not redistribute copyrighted content without permission.
